## 什么句子是主谓宾句型
---
判断方式： 主语后面是“动作（动词）”

| 判断方式 | 主语后面是“动作（动词）” |
| -------- | ------------------------ |
| 动词     | （身体）看、跑、吃、说等（心理）想、思念、爱、决定   |


### 用主谓宾句型翻译句子

| 中文         | 英文                                                                 |
| ------------ | -------------------------------------------------------------------- |
| 我爱你       | I love you                                                           |
| 他爱你       | He <mark style="background: #FF5582A6;">loves</mark> you             |
| 你吃面条     | You eat noodles                                                      |
| 这个人吃面条 | This person <mark style="background: #FF5582A6;">eats</mark> noodles |
| 我跑步       | I run                                                                |
| 他们跑步     | They run                                                             |
| 她跑步       | She <mark style="background: #FF5582A6;">runs</mark>                 |
| 我的妈妈吃饭 | My mom eats rice                                                     |
| Tom吃饭      | Tom eats rice                                                                     |

### 谓语动词变形

| 主语      | 变化  |
| --------- | ----- |
| 我        | 不变  |
| 你        | 不变  |
| 他/她/它  | <mark style="background: #FF5582A6;">变 +s</mark> |
| 数量为1   | <mark style="background: #FF5582A6;">变 +s</mark> |
| 数量大于1 | 不变      |


### 宾语存在动词需变形

| 已经做了（being） | 还没做（to be） |
| -------- | ------ |
| 后面 +ing     | 前面 +to       |

| 中文               | 英文                        |
| ------------------ | --------------------------- |
| 我爱吃面条。       | I love <mark style="background: #FF5582A6;">eating</mark> noodles.      |
| 他爱吃面条。       | He loves <mark style="background: #FF5582A6;">eating</mark> noodles.    |
| 你喜欢吃米饭。     | You love <mark style="background: #FF5582A6;">eating</mark> rice.    |
| 这个人喜欢睡觉。   | This person loves <mark style="background: #FF5582A6;">sleeping</mark>. |
| 我想离开这里。     | I want <mark style="background: #FF5582A6;">to leave</mark> there.      |
| 他们决定乘坐大巴。 | They decide <mark style="background: #FF5582A6;">to take</mark> a bus.   |
| 她拒绝帮助你。     | She refuses <mark style="background: #FF5582A6;">to help</mark> you.                            |
