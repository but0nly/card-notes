### 什么是否定句

| 定义 | 表达“不”、“否”、”没有“等否定意思 |
| ---- | -------------------------------- |
|      |                                  |


### 主系表句型的否定句
回顾： 主系表句型：（系动词是很在）
规则： 系动词后加 `not`

| 中文           | 翻译                         |
| -------------- | ---------------------------- |
| 我不是你的哥哥 | I am not your brother.       |
| 他不帅         | He is not handsome.          |
| 你不无聊       | you are not boring.          |
| 这件事情不重要 | This is not important. |
| 他们不在那里   | They are not here.                             |


### 主谓宾句型的否定句
回顾： 主谓宾句型： （主语后 动词 动作）

规则： 主语后加 `don't/ doesn't`
什么时候用`doesn't` ： 当主语为`他/她/它`或者`数量为1`时

| 中文             | 翻译                                 |
| ---------------- | ------------------------------------ |
| 我不爱你         | I don't love you.                    |
| 他不说英语       | He doesn't speak English.            |
| 我不知道         | I don't know.                        |
| 我的小狗不喝羊奶 | My puppy doesn't drink goat milk. |
| 他们不想离开你   | They don't want to leave you.                                     |


### there be 句型否定句

规则：there is no 没有

| 中文           | 翻译                          |
| -------------- | ----------------------------- |
| 这里没有人     | There is no body.             |
| 杯子里面没有水 | There is no water in the cup. |
| 抽屉里没有钱   | There is no money in the drawer.                              |
