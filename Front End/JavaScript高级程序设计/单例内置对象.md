#JavaScript 

## Global对象
---
JavaScript中最特别的对象，代码不会显式的访问它。
ECMAScript规定 `Global`是一种兜底对象，它所针对的是不属于任何对象的属性和方法。
实际上在全局作用域中定义的变量和函数都会变成 `Global` 的属性。

Global 的方法：
- `isNaN`
- `isFinite`
- `parseInt`
- `parseFloat`
- URI编码方式
	- `encodeURI`
	- `encodeURIComponet`
	- `decodeURI`
	- `decodeURICompone`
- 强大的`eval`
	- 就是一个 `JavaScript`的解析器


Global的属性：
- undefined
- NaN
- Infinite
- Object 
- Function
- Array
- String
- Number
- Boolean
- Date
- RegExp
- Symbol
- Error
- EvalError
- RangeError
- ReferenceError
- SyntaxError
- TypeError
- URIError


### window对象

虽然 ECMAScript 没有规定直接访问 `Global` 对象的方式，但是浏览器将 `window` 对象实现对 `Global` 对象的代理
