
### 语法

| 操作                                  | 键位 |
| ------------------------------------- | ---- |
| operator + （内部/外部）+ 文本对象    | i    |
| 可视化模式 + （内部/外部） + 文本对象 | a    |
|                                       |      |

### 文本对象

| 目标 | 键位 |
| ---- | ---- |
| 单词 | w |
| 括号（） | `（`或`）`、b |
| 中括号`[]` | `[`或`]` |
| 大括号`{}` | `{`或`}`、B |
| 大于小于符号号<> | `<`或`>` |
| xml标签 | t |
| 单引号‘’ | ‘ |
| 双引号”“ | “ |
| 反引号\` | \` |
| 句子 | s |
| 段落 | p |


### VSCODE VIM 插件自带的功能

- vim-textobj-argument

| 操作 | 键位 |
| ---- | ---- |
| 不包含分隔符 | ia |
| 包含分隔符 | aa |
| 删除一个参数 | daa |
| 修改一个参数 | cia |

- vim-textobj-entire

| 操作                 | 键位 |
| -------------------- | ---- |
| 删除当前文本所有内容 | dae  |
| 删除当前文本所有内容，但不包括前面和后面的空格                     | die     |
