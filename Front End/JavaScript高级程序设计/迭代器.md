#JavaScript 

## 迭代器协议
---
迭代器是一种一次性使用的对象，用于迭代与其关联的可迭代对象。

```js
const arr = ['foo', 'bar'];
// iterator 为迭代器
const iterator = arr[Symbol.iterator]();
console.log(iterator.next()); // { done: false, value: 'foo'}
console.log(iterator.next()); // { done: false, value: 'bar'}
console.log(iterator.next()); // { done: true, value: undefinded}
```

- `next()` 
	- 返回迭代器对象包含的两个熟悉 `done`和 `value`
	- `done` 是一个布尔值，表示是否还可以继续调用 `next` 获取下一个值
	- `value` 包含可迭代对象的下一个值，当`done` 为 `false` ，`value`为`undefinded`

### 自定义迭代器
---

```js
class CustomIterator{
  constructor(limit){
    this.limit = limit
  }

  [Symbol.iterator](){
    let count = 1;
    const limit = this.limit
    return {
      next(){
        if(count <= limit){
          return { done: false, value: count++}
        } else {
          return { done: true, value: undefined}
        }

      }
    }
  }
}



const iter = new CustomIterator(3);

for (const iterator of iter) {
  console.log(iterator); // 1，2，3
}
```


## 提前终止迭代器
---
迭代器的`return`方法会在终止迭代时调用，例如`break`、`continue`、`return`、`throw`

```js
class CustomIterator{
  constructor(limit){
    this.limit = limit
  }

  [Symbol.iterator](){
    let count = 1;
    const limit = this.limit
    return {
      next(){
        if(count <= limit){
          return { done: false, value: count++}
        } else {
          return { done: true, value: undefined}
        }

      },

      return(){
        console.log('Exiting early');
        return { done: true, value: undefined}
      }
    }
  }
}



const iter = new CustomIterator(3);

for (const iterator of iter) {
  if(iterator > 2){
    break;
  }
  console.log(iterator);
}

// 1
// 2
// Exiting early

```
