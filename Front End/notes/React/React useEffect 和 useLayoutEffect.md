
### 两者区别

| 特性   | useEffect  |     | useLayoutEffect    |
| ---- | ---------- | --- | ------------------ |
| 执行时机 | 在浏览器渲染之后执行 |     | 在DOM更新之后，浏览器渲染之前执行 |
| 是否同步 | *异步*执行     |     | *同步*执行             |
| 影响   | 会渲染两次      |     | 会堵塞渲染              |
| 速度   | 执行更快       |     | 比useEffect慢        |
