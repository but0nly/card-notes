#面试题 

### 深拷贝定义
顾名思义，就是对复杂类型进行拷贝。然后返回一份新的数据（新的引用内容）


### 手写实现
**思路**：利用递归去深度查找，然后赋值到新的对象、数组中。

- 仅支持对象、数组
- 不支持循环调用
- 不支持Set、Map、Symbol等内置构造函数

```js
function deepClone(target){
  if(typeof target !== 'object' && target !== null) return target;

  let results;
  if(target instanceof Array){
    results = [];
  }else{
    results = {}
  }

	// 通过for in去遍历，对数组和对象都有效
  for (const key in target) {
    if(Object.hasOwnProperty.call(target, key)){
      results[key] = deepClone(target[key]);
    }
  }

  return results;
}

deepClone({
  foo: 'bar',
  baz: [1, 2, 3, 4]
});  // { foo: 'bar', baz: [ 1, 2, 3, 4 ] }

```
