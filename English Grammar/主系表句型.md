### 什么是主系表句型

| 判断方式 |
| -------- |
| 是       |
| 很       |
| 在         |

主语 + 系动词（是很在）+ 表语
例句：
这是我的妈妈。
这 this + 系动词 + 我的妈妈 my mom
我很累。
我 I + 系动词 + 累 tired

### 系动词该选哪一个

| 主语      | 系动词 |
| --------- | ------ |
| 我        | am     |
| 你        | are    |
| 他/她/它  | is     |
| 数量为1   | is     |
| 数量大于1 | are       |
