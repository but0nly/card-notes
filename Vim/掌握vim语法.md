#vim
### vim语法

操作（operator） + 动作（范围）

### 操作

| 操作                 | 键位 |
| -------------------- | ---- |
| 删除                 | d    |
| 删除并进入insert模式 | c    |
| 复制                 | y     |


### 基于单词/字串移动

| 操作                   | 键位 |
| ---------------------- | ---- |
| 移动到单词的结尾       | e    |
| 移动到上一个单词的开头 | b    |
| 移动到单词的开头       | w    |
| 移动到上一个单词的结尾 | ge（不常用）     |

### 组合

| 操作           | 键位 |
| -------------- | ---- |
| 删除当前单词   | cw   |
| 在单位尾部输入 | ea     |
