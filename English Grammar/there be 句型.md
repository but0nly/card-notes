### 什么是there be句型

| 判断方式            |
| ------------------- |
| 表达"某个地方有..." |


例句：
<mark style="background: #FF5582A6;">桌上有</mark>一台红色的电脑。
<mark style="background: #FF5582A6;">车上有</mark>很多人


### 用there be 句型翻译句子

| 中文                   | 英文                                |
| ---------------------- | ----------------------------------- |
| 桌上有一台红色的电脑。 | There is a red compute on the desk. |
| 车上有很多人。         | There are many people on the bus.   | 
| 这里有一些书。         | There are some books here.        |
| 那里有一个女孩。       | There is a girl there.           |
| 床上有一只小狗。       | There is a puppy on the bed.        |
