### 什么是疑问句

| 定义 | 用来提问的句子 |
| ---- | -------------- |
|      |                |

### 疑问句的分类

| 直接回答 | 具体回答 |
| -------- | -------- |
| yes/no   | 具体时间、具体事或人         |


### 主系表句型的直接提问句

规则： 系动词提前

| 中文             | 翻译                   |
| ---------------- | ---------------------- |
| 它是你的小狗吗？ | Is it your puppy？     |
| 他很帅吗         | Is he handsome？       |
| 这很有趣吗       | Is this interesting？  |
| 英语很重要吗     | Is English important？ |
| 他们在那里吗     | Are they there？                       |

### 主系表句型的详细疑问句

规则：疑问句+系动词

| 中文                 | 翻译                    |
| -------------------- | ----------------------- |
| 你是谁?              | Who are you？           |
| 你的生日是什么时候？ | When is your birthday？ |
| 你的名字是什么？     | What is your name？     |
| 他们在哪里？         | Where are they？        |
| 哪个是正确的         | Which is right？                        |


### 主谓宾句型的直接疑问句

规则： `do/does` 放句首
如果是does，动作变形还原 drinks -> drink

| 中文               | 翻译                              |
| ------------------ | --------------------------------- |
| 你爱我吗？         | Do you love me？                  |
| 你说英语吗？       | Do you speck English？            |
| 你知道吗？         | Do you know？                     |
| 你的小狗喝羊奶吗？ | Does your puppy drink goat milk？ |
| 他想离开你吗？     | Does he want to leave you？                                  |


### 主谓宾句型的详细疑问句

规则： 疑问句 + `do/does` 放句首

| 中文                   | 翻译                        |
| ---------------------- | --------------------------- |
| 你爱谁？               | Who do you love？           |
| 你去哪里？             | Where do you go？           |
| 你知道什么？           | What do you know？          |
| 你为什么喜欢这个男孩？ | Why do you love the boy？ |
| 她如何学英语           | How does she learn English？                            |


### there be 句型的直接疑问句

规则： Is there

| 中文                 | 翻译                            |
| -------------------- | ------------------------------- |
| 这里有一些人吗？     | Is there anybody here？         |
| 杯子里面有一些水吗？ | Is there any water in the cup？ |
| 附近有一个音乐吧吗？ | Is there any a live house nearby.                                |


### there be 句型的详细疑问句

规则： `how many...` + are there + 地点

| 中文               | 翻译                                     |
| ------------------ | ---------------------------------------- |
| 大厅里有多少人？   | How many people are there in the hall.   |
| 教室里有多少男孩？ | How many boys are there in the classroom. |
| 盒子里有多少球？   | How many balls are there in the box.                                         |



### 总结

| 句型                | 规则                      |
| ------------------- | ------------------------- |
| 主系表直接疑问句    | 系动词提前                |
| 主系表详细疑问句    | 疑问句 + 系动词提前       |
| 主谓宾直接疑问句    | `do/does` 放句首          |
| 主谓宾详细疑问句    | 疑问句 + `do/does` 放句首 |
| there be 直接疑问句 | `Is there`                  |
| there be 详细疑问句 | `How many...` + `are there` + 地点                          |
