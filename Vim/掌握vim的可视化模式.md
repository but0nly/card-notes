# 掌握vim可视化模式

| 操作 | 键位 | 
| --- | --- | 
| 字符 | v |
| 行 | V |
| 块 | Ctrl + v |

### 导航

| 操作                 | 键位 |
| -------------------- | ---- |
| 切换可视区域光标位置 | o    |
| 回到上一次选择的区域 | gv     |

### 跨多行编辑

| 操作                  | 键位       |
| --------------------- | ---------- |
| 给多个行的后面加分号; | 配合A或者I |
| 赋值粘贴              | 利用系统的剪切板           |

### 技巧

尽可能的少用可视化模式 - 会增加操作步骤

const a = 1;
const b = 2;
